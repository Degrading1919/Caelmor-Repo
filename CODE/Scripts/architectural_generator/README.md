# Caelmor Architectural Generator

A Blender add-on for generating editable, metre-scale Lowmark building exteriors. Geometry is built from Caelmor's original Python mesh code and can be regenerated by semantic layer.

The primary technical reference is the supplied `Caelmor_Architectural_Generator_Research.md`, retained beside this README. Its recommendations informed this implementation; embedded proposals and approval requests are reference material. This is offline art-authoring tooling. It does not alter Caelmor's runtime generation policy, Unity code, game schemas, or regional canon.

## Architecture and extension points

`model.py` produces a semantic plan from supported orthogonal massing rules and independent named seed streams. `geometry.py` constructs closed parametric solids. `facade.py` subdivides real wall apertures and creates framing, masonry, joinery and details. `roof.py` clips competing gable planes to their analytic upper envelope, welds deck seams, and clips individual shingle courses to the resolved valleys. No prefab meshes, skeleton library, external Python packages, or downloaded textures are required by the installed add-on.

`blender_backend.py` separates authoring geometry from Blender objects, UVs, protected overrides, and export. `materials.py` contains the Lowmark palette and original periodic color/normal image generation; images are packed into the Blender file and embedded in GLB exports. Named semantic layers and the plan/mesh separation provide extension points for future regional grammars, interior room planning, and optimized export compilation. Those extensions are not implemented in this release.

## Requirements and installation

- Blender 5.0.1 is the tested target. The extension manifest declares Blender 4.2 as its minimum; other Blender releases have not been validated.
- Use the packaged add-on ZIP at `dist/caelmor_architecture.zip`; its `blender_manifest.toml` is at the ZIP root.
- In Blender, open **Edit → Preferences → Get Extensions**, use the menu to choose **Install from Disk**, and select the ZIP. Enable **Caelmor Architectural Generator** if Blender does not enable it automatically.
- Open a 3D View and find the **Caelmor** tab in the N-panel.

To rebuild the distributable after source changes, run `py -3 package_addon.py` from this directory. The script writes `dist/caelmor_architecture.zip`. The extension sources and full GPL license are included in the package.

## Use

Choose a building function, footprint, dimensions, floors, roof pitch, detail level, window density, and seed, then select **Generate New**. A Caelmor Building collection is created and stores its settings and generation metadata. **Load Selected Settings** restores a building's saved settings to the panel. **Regenerate Selected** replaces generated geometry in all layers or the chosen roof, windows/doors, or details scope. Untagged objects in the building collection are preserved.

Use **Protect / Unprotect Selected** to retain an edited generated mesh through later regeneration. Protected buffers are skipped during regeneration, included in exports, and listed in the manifest with their protected state; unprotect the object to restore procedural replacement.

Supported building functions are Farmhouse, Barn, Grain Store, Miller, and Inn. Footprints are rectangular, L, T, and U; the generator does not accept arbitrary drawn polygons or hip roofs. The generated buildings are exterior shells and are not enterable; this release does not generate interiors. It creates approximate static wall and footprint collision proxies and exports them separately, with counts and limitations in the sidecar manifest. They have not been validated for traversal or in Unity.

The current parameter guards require width 6–24 m, depth 4–16 m, 1–3 floors, and wings at least 2.5 m wide. For L/T/U footprints, wing width cannot exceed the main depth. U footprints keep at least 2 m of courtyard clearance. L footprints may mirror and T wings may shift with the seed; U wings may have unequal depths. These variations preserve the footprint area.

## Python API

With Blender's Python environment and the add-on available on `sys.path`:

```python
from caelmor_architecture.model import Settings, make_plan
from caelmor_architecture.engine import generate, validate, geometry_hash
from caelmor_architecture.blender_backend import build, export_building

settings = Settings(seed=17, function="FARMHOUSE", footprint="L")
plan = make_plan(settings)
plan, buffers = generate(settings)
report = validate(plan, buffers)
collection, metrics = build(settings)
sidecar_path = export_building(collection, r"C:\temp\farmhouse.glb")
```

`generate` is pure Python and does not require Blender. `build` creates/replaces generated objects in Blender; `export_building` writes a glTF binary (`.glb`) or separate glTF (`.gltf`) plus a `.caelmor.json` sidecar. The sidecar contains saved settings, geometry hash, units, semantic layers, and per-object material/layer metadata. Export is an interchange artifact only: this package does not claim Unity import, collision, lighting, or runtime validation.

Generated meshes carry metric UV0 and packed UV1 lightmap coordinates, material names, and semantic layer metadata. The add-on generates and packs original tileable 128×128 base-color and tangent-normal maps for wood, stone, plaster, and roof surface families; materials tint these maps with the muted Lowmark palette. The GLB export embeds supported material images. Blender's glTF exporter controls the material features that survive export; inspect exports in the target pipeline before production use.

## Development checks

From this directory, use Python 3.11+ (or Blender 5.0.1's bundled Python) for pure geometry checks, and Blender 5.0.1 for the scene integration suite:

```powershell
py -3 -m unittest discover -s tests -p "test_generator.py" -v
py -3 -m unittest discover -s tests -p "test_geometry.py" -v
& "C:\Program Files\Blender Foundation\Blender 5.0\blender.exe" --background --python tests/test_blender.py
& "C:\Program Files\Blender Foundation\Blender 5.0\blender.exe" --background --python tests/render_evidence.py
py -3 verify_install.py
```

`tests/render_evidence.py` generates a bounded visual evidence set in `evidence/`: `hero.png`, `overview.png`, a four-angle `ten_buildings_four_views.png` contact sheet, a `ten_buildings.blend` scene, and `evidence_manifest.json` with the Blender version, full input settings, pure geometry validation counts/hashes, and generated object/bounds counts. The example set uses all five building functions with distinct footprints and includes a dimension-edited farmhouse. The isolated installed-extension export check also writes `farmhouse.glb`, `farmhouse.collision.glb`, and `farmhouse.caelmor.json`. These checks are generator-level verification, not a Unity benchmark or a substitute for review in the target game engine.

See [tests/VALIDATION.md](tests/VALIDATION.md) for the executed test and render record.

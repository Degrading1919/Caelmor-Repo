# Caelmor — Hunting Representative Methods and Calibration

**Status:** Proposal-stage numerical calibration for Creative Director audit
**Scope:** Representative Hunting methods from level 1 through 99; no exact unlocks, final timings, final fauna, prices, yields, or implementation data

## 1. Calibration authority and rules

This proposal uses the authoritative cumulative XP thresholds:

| Milestone | Cumulative XP | Nominal engaged time |
|---:|---:|---:|
| 30 | 221,617 | ~11 h |
| 50 | 652,858 | ~31 h |
| 70 | 1,549,627 | ~63 h |
| 80 | 2,324,814 | ~90 h |
| 99 | 5,000,000 | ~145 h |

The same authored Hunting action under the same conditions awards the same base XP regardless of player level. A later method earns more XP per hour only because it contains genuinely more demanding authored actions, reduces avoidable travel and failed work, combines known opportunities efficiently, or uses later-approved preparation, tools, or access.

All seconds in this document are analytical complete-loop assumptions. They do not set animation locks, action times, respawn behavior, or production tuning.

## 2. What counts as a Hunting method

A representative method is a complete repeatable loop:

```text
source opportunity
→ read and prepare
→ approach and resolve
→ Hunting recovery / compressible field dressing
→ keep / bank / process / sell / supply
→ return or continue route
```

An animal relationship is not a method by itself. The same provisional fauna function can support different methods when evidence, habitat, access, recovery, route, or destination changes.

## 3. Fixed authored-action XP vocabulary

The values below are provisional but fixed by authored activity. Similar labels do not imply identical actions: a short margin read and a dual-layer hazard diagnosis have different conditions and therefore different fixed rewards. Reused actions retain their original XP in circuits.

| Method ID | Fixed authored actions | Loop base XP |
|---|---|---:|
| HM1 | Current-sign read 110; bounded approach 170; ordinary resolution 240; compact recovery 180 | 700 |
| HM2 | Claim/sign verification 160; output preparation 140; territorial approach 220; bounded resolution 300; qualifying field recovery 280 | 1,100 |
| HM3 | Flock read 140; wet-ground preparation 100; alert-aware approach 210; flock resolution 270; ordinary recovery 180 | 900 |
| HM4 | Movement diagnosis 240; return staging 180; interception approach 320; movement-window resolution 420; route-sensitive recovery 340 | 1,500 |
| HM5 | Route read 220; output preparation 180; group approach 290; grazer resolution 400; full field recovery 360 | 1,450 |
| HM6 | Target/hazard diagnosis 400; hazard preparation 260; constrained approach 360; Hunting eligibility confirmation 420; dangerous recovery 760 | 2,200 |
| HM7 | Testimony review 600; site comparison 650; response planning 500; justified resolution 850; custody/accounting 600 | 3,200 |
| HM8 | One HM3 opportunity + one HM4 opportunity + one HM5 opportunity; no circuit bonus XP | 3,850 |

**Provisional Hunting XP/action range:** 100–850 XP for the represented fixed actions.

Normal combat XP, if any, is outside this model. Combat may resolve dangerous contact in HM6, but HM6 Hunting XP still comes from reading, preparation, eligibility, and recovery. Combat victory alone grants no Hunting recovery or Hunting XP bundle.

HM7 can resolve through a justified hunt, redirection, delay, or refusal. Its fixed inquiry actions reward correct evidence work and accountable resolution; they do not create a no-risk stationary XP station. Access is occasional and authored, so HM7 cannot be the default throughput method.

## 4. Representative method portfolio

### HM1 — Familiar margin forage

| Dimension | Proposal |
|---|---|
| Progression role | Novice; reliable low-attention method that remains useful later |
| Opportunity pattern | HN-01 guided margin forage; F1 small margin forager |
| Complete loop | Read nearby sign → short bounded approach → resolve → compact recovery → household, storage, or baseline market → return |
| Why choose it | Familiar route, low preparation, low risk, convenient food relationship, easy banking |
| Attention / knowledge | Low after the signs and safe margin are learned |
| Risk | Low; active work or unsafe proximity can close an instance |
| Outputs | One edible recovery relationship per successful loop; no hide requirement |
| Banking / processing burden | Low when the margin is paired with a normal household or market route; exact placement requires map verification |
| Self-supply value | Future Cooking and household food flow |
| Economic value | Dependable but ordinary baseline food value; no premium material |
| Mastery improvement | Fewer false approaches, cleaner route chaining, less return travel |
| Later relevance | Convenient food/self-supply and a stable familiar routine near ordinary destinations |

| Dimension | Proposal |

## 5. Loop calibration

The calculation is:

```text
effective XP/hour = loop base XP × 3,600 / complete-loop seconds
```

| Method | Base XP/loop | Baseline loop assumption | Baseline XP/h | Knowledgeable loop assumption | Efficient XP/h | Baseline output pressure |
|---|---:|---:|---:|---:|---:|---|
| HM1 Familiar margin forage | 700 | 150 s | 16,800 | 135 s | 18,667 | 24 edible recovery events/h |
| HM2 Rooter response | 1,100 | 200 s | 19,800 | 180 s | 22,000 | 18 edible events/h; up to 18 hide-qualified recoveries/h when source eligibility is met |
| HM3 Reed-margin circuit | 900 | 145 s | 22,345 | 132 s | 24,545 | 24.8 edible recovery events/h |
| HM4 Movement-window route | 1,500 | 195 s | 27,692 | 178 s | 30,337 | 18.5 edible events/h; hide depends on final source expression |
| HM5 Grazer supply route | 1,450 | 225 s | 23,200 | 200 s | 26,100 | 16 edible and up to 16 hide-qualified recoveries/h |
| HM6 Hazard recovery | 2,200 | 250 s | 31,680 | 225 s | 35,200 | 14.4 underlying-source recoveries/h before failed/declined attempts |
| HM7 Inquiry commission | 3,200 | 390 s | 29,538 | 345 s | 33,391 | Zero to ordinary underlying output; not treated as a bulk supply route |
| HM8 Mixed circuit | 3,850 | 308 s | 45,000 | 288.75 s | 48,000 | 35.1 edible recovery events/h; roughly 11.7 hide-eligible events/h from its single representative hide leg |

“Output event” is an analytical relationship count, not a final item quantity or yield. Failed, declined, closed, or invalid opportunities reduce realized throughput. Final rates require playtesting and map verification.

## 6. Modeled progression paths

### Calibration reference path

The reference is a plausible mixed path, not an unlock schedule:

- Novice XP: 30% from HM1 and 70% from HM2 at baseline execution;
- Competent XP: HM3 baseline;
- Advanced XP: HM4 baseline;
- Masterful approach to 80: HM6 baseline;
- post-80: HM8 baseline.

### Sustainable knowledge-efficient path

Knowledgeable execution does not make every high-rate opportunity continuously available. HM6 requires an actual hazard-complicated recovery, HM7 requires a bounded authored inquiry, and HM8 requires all three constituent opportunities to be simultaneously valid along a credible route. A sustainable expert therefore uses those methods when their real conditions exist and returns to durable HM4/HM5 supply routes between them.

The modeled XP shares are analytical portfolio shares, not exact unlocks or scheduled throttles:

- Novice: the same 30% HM1 / 70% HM2 mix at knowledgeable cadence;
- Competent: HM3 at knowledgeable cadence;
- Advanced: 82% HM4 and 18% HM5;
- Masterful approach to 80: 25% HM6, 65% HM5, and 10% HM7;
- post-80: 80% HM8, 10% HM6, 5% HM5, and 5% HM7.

This mix preserves knowledge benefits inside every closed envelope. It uses no waiting, random closure, fake travel, downtime, or XP scaling. The slower segment averages follow from the methods' actual purpose and availability: focused grazer supply remains repeatable, while hazards, inquiries, and complete mixed circuits are conditional opportunities.

## 7. Player-strategy tests

| Strategy | Likely methods | Why it is legitimate | Dominance control |
|---|---|---|---|
| Pure XP | HM3 → HM4 → HM6 → HM8 | Strong action density and route knowledge | Less focused hide output; higher attention/risk; HM8 requires several valid opportunities and verified geography |
| Profit/output | HM2 and HM5 | Food, hide, renderer, household, tannery, and market value | Lower XP/h than band leaders; higher processing burden |
| Self-supply | HM2 and HM5, selected HM8 legs | Sustained raw hide and food relationships | Eligibility, recovery, and Leatherworking time prevent universal XP dominance |
| Low attention / familiar route | HM1 and learned HM3 route | Stable cues, low preparation, convenient returns | Lower XP ceiling and narrower output mix |
| Knowledge-efficient | HM4, HM6, HM8 | Avoids stale work, reduces travel/waste, protects recovery | Benefits require actual reading and route validity; no numerical player-level multiplier |
| Post-Practical-Mastery | HM8 plus optional HM7 and focused HM5 | Route refinement, civic meaning, supply goals, identity | No mandatory daily content, exclusive material, or singular best objective |

No method wins XP, profit, self-supply, convenience, low attention, safety, and civic value simultaneously.

## 8. Throughput and sink pressure

- HM2/HM5 can produce roughly 16–18 hide-qualified recovery events per baseline hour when every selected final source is eligible. This could exceed early Leatherworking demand if hide item yields are generous.
- HM8 creates the highest broad food pressure: about 35 edible recovery events and 11.7 hide-eligible events per modeled baseline hour before failed or invalid opportunities.
- The dependable baseline market prevents stranding but must not become a premium deletion sink. Cooking demand, household use, Leatherworking, ordinary tannery demand, renderer flow, storage, and market value must be tuned together.
- HM7 deliberately produces inconsistent material throughput; its value comes from authored judgment and civic resolution.
- Exact item quantities remain unset. Output-event pressure should inform later yield and sink tests rather than creating new byproducts.

## 9. Risks and playtest assumptions

1. **Sustainable method shares:** playtesting must verify that ordinary HM4/HM5 availability and conditional HM6/HM7/HM8 access resemble the modeled portfolio without becoming authored throttles.
2. **HM8 geography:** the circuit works only if map verification supports a credible three-opportunity route. It must be replaced or split if it depends on invented adjacency.
3. **Hide oversupply:** final fauna eligibility and item yields must keep HM2/HM5 useful without flooding Leatherworking and market sinks.
4. **HM6 combat boundary:** prototypes must confirm that Hunting ownership remains clear when normal combat resolves danger.
5. **HM7 exploit risk:** inquiry XP requires authored evidence and bounded availability; it cannot become a stationary repeat dialogue loop.
6. **Attention claims:** “low attention” and “high attention” need input and failure testing, not only narrative judgment.
7. **Field-dressing compression:** the recovery step must stay meaningful where condition matters and disappear as a redundant click elsewhere.

## 10. Hunting calibration result

Eight methods cover the five progression identities. Fixed authored actions in the provisional **100–850 XP/action** range produce a baseline method range of **16,800–45,000 XP/hour** and a knowledgeable method range of **18,667–48,000 XP/hour**. The reference path reaches the authoritative milestones in approximately **11.79 / 31.09 / 63.48 / 87.94 / 147.39 hours**; the sustainable knowledgeable path reaches them in **10.61 / 28.18 / 58.61 / 85.74 / 147.06 hours**.

The portfolio supports XP, output, self-supply, low-attention, knowledge-efficient, and post-mastery play without adding fauna, materials, hidden level multipliers, or a universal dominant method.
